# Grimoire Demo (2-3 min)

Pre-load Hemingway in the first box before you hit record.

---

Every writer has a statistical DNA. Sentence length, syllable density, comma cadence. Patterns so consistent you can identify an author from a paragraph. Grimoire makes that DNA visible.

[click Diagnose My Writing]

This is Hemingway. 84% monosyllables. Six-word sentences. Zero semicolons. That 3D shape is a projection of seven metrics. The more angular and asymmetric the shape, the more distinctive the voice.

[click Start Over, load Kafka in box 1, load Hemingway in box 2, click Compare Voices]

Now look at Kafka next to Hemingway. Totally different radar. Longer sentences, denser punctuation, richer vocabulary. Distance: 0.18. Two different literary DNAs.

The question is: can we close that gap with an agent?

[click Run Style Coach]

The agent generates three candidates per round at different temperatures. Each one gets scored against the target fingerprint. Best survives. The gap analysis feeds back into the next round. Five rounds of selection pressure.

[wait for coaching to finish, or talk over the spinner]

Watch the distance drop. Round one it's guessing. By round three it's locking onto the target metrics. By five it's converged.

[scroll through the coached view]

Three shapes side by side. The original, the coached version, the target. You can see the coached shape pulling toward Hemingway's profile. And the text itself: shorter sentences, simpler words, stripped-down punctuation.

[scroll to judge]

Final check: a separate LLM reads both texts blind and decides if they're by the same author. It doesn't know which is the coached output. [read the verdict off screen].

Grimoire. Paste any text, target any voice, watch an agent converge with statistical proof. Built with Next.js, Vercel AI SDK, and Gemini.
